# WSK 官网前端开发约定

适用范围：本目录及其子目录。

开始前阅读 `../docs/frontend-style-guide.md`。其中的“当前确认版本”是现有官网的样式基线；用户本次明确要求可调整它。

## 必须保持的基线

- 品牌为 **WSK · World Super Kinetic**；以用户提供的银色流线 W 车标为准，不替换成 V、羽翼或其他标志。
- 页头和首页 02 设计区采用同一深色 `#181B24`；页头文字、车标为浅色。车标没有独立渐变底板。
- 导航顺序为“了解我们 / 探索车型 / 设计与灵感 / 品牌体验”，四项同属 nav，间距一致。
- 主要浅色背景 `#F6F6F1`，通用强调橙 `#FF5701`；“预览风采”与品牌体验区小圆点使用蓝 `#2563EB`。
- 按钮、间距、字体、响应式和无障碍细则依照样式规范，不另起一套视觉体系。
- 首页预览影片在原区域播放：点击后介绍淡出，播放结束自动恢复介绍与按钮；保留原生播放控制、“返回介绍”和 Esc 返回。
- 保留首页、品牌页、车型页三个入口；“探索车型”跳转独立车型页，不退回仅滚动到首页卡片。

## 实现与验证

- 当前技术栈：原生 HTML/CSS/JavaScript + Vite 多页面构建。源码在本目录根部，媒体在 `public/assets/`，构建产物在 `dist/`。
- 保留 Vite 的三个 HTML 构建入口与现有 API 代理。不要编辑构建产物替代源码。
- 默认沿用现有技术栈；不要为普通视觉修改引入 React、组件库或新的构建系统。
- 保持可读、可维护的源码；修改现有规则或组件样式，避免反复追加相互覆盖的临时规则。
- 完成对应检查：前端源码变更运行 `npm run build`；交互与布局变化检查代表性桌面和手机尺寸。纯文档修改无需重跑前端构建。
- 不要把 `node_modules/`、`dist/`、环境密钥或平台登录凭据提交进 Git。
- 当前没有真实车型与试驾预约 API。增加接口前先查 `../docs/frontend-api-map.md`；演示表单不能声称数据已保存。
